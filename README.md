# stressbar
A web-based mental wellbeing and stress tracking platform with chatbot support, built using HTML, CSS, PHP, MySQL, and XAMPP.

StressBar is a small web space created to help users pause, reflect, and express how they feel.  
It offers a gentle chat-like interface and simple mood reflection so users can notice stress and thoughts in a safe, private way.

---

## What it does

- lets users share how they are feeling  
- helps identify sources of stress  
- stores reflections for later view  
- provides a calm chat-style interaction  
- keeps everything simple and personal  

---

## Built with

- HTML  
- CSS  
- JavaScript  
- PHP  
- MySQL  
- Apache (XAMPP)  

---

## How to run locally

1. Install **XAMPP**
2. Copy the project folder into  
   `xampp/htdocs/stressbar`
3. Open **phpMyAdmin**
4. Create a database named  
   `stressbar_db`
5. Import the SQL file from the project
6. Start Apache and MySQL
7. Open in browser:  
   `http://localhost/stressbar`

---

## Why this project

Many people carry stress quietly.  
StressBar was created as a small digital space where someone can slow down for a moment and check in with themselves.
